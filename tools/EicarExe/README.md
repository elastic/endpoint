# EicarEXE
EicarEXE is a benign Windows executable that contains the [EICAR string](https://en.wikipedia.org/wiki/EICAR_test_file).

Users can run this application to test whether Malware Protection is actively detecting and/or preventing malicious executables from running.

# Building
Compile `EicarExe.slnx` with Visual Studio 2026.
